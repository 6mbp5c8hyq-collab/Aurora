# AURORA Chemistry Workbench

The native iOS Chemistry Workbench calls the canonical Railway chemistry authority rather than reimplementing scientific chemistry in Swift.

Surfaces:
- Chemistry capability and authority boundary.
- Runtime chemistry self-test.
- Aqueous equilibrium/speciation execution.
- Saturation-index execution.
- Generic kinetic reaction execution.
- Species tables, phase saturation, kinetic trajectories, solver diagnostics and provenance.

The client deliberately does not contain Pitzer/SIT/CD-MUSIC equations or parameter tables. High-fidelity model authority remains server-side so database versions, parameter fingerprints, benchmark status and release gates remain centralized.
